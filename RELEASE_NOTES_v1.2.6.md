## Highlights

- One-click DLSS 5 mod installation for supported games.
- Game library scanner for Steam, Epic Games, GOG Galaxy, and local installs.
- DLSS / FSR / XeSS / Streamline detection per game.
- Install routes for OptiScaler, ReShade, DX12, DX11, DX9, AMD, and emulators.
- Local install manifests and backups for remove/repair flows.
- Fast local cache under `%LOCALAPPDATA%\DLSS5Manager\`.

## Install

1. Download the ZIP below.
2. Extract it anywhere.
3. Run `DLSS 5 MANAGER.exe`.
4. If Windows blocks it, choose **More info** → **Run anyway**.
5. Run as administrator if the target game is in a protected folder.
